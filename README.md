# GeoGuessr Clues

My own notes on telling countries apart in GeoGuessr. Short, checkable clues — the kind you can
actually spot in the two seconds before you pan the camera.

Each document covers a group of countries that get confused with each other, ordered by how
reliable the clue is: strongest discriminator first.

## Documents

| Document | Covers |

| [Costa Rica vs. Panama vs. Ecuador](docs/costa-rica-panama-ecuador.md) | CR / PA / EC |

## How the notes are written

- **Unique** — this clue alone identifies the country.
- **Strong** — right most of the time, but confirm with a second clue.
- **Soft** — a nudge, never a decision on its own.
