# Uruguay

**Trident pole** — pole top with **three insulators pointing straight up**.

Uruguay uses several pole types, but this one is common and neither **Argentina** nor **Brazil**
has it. Seeing it settles the border regions.

**Mnemonic:** a **U** with a spike in the middle = trident → **U**ruguay.

Source: [plonkit.net/uruguay](https://www.plonkit.net/uruguay).
