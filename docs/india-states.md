# India — states

Only once you know it is India. The script on a sign is the strongest regional clue — read that
first, poles second.

## Script

| Look for | State |
|---|---|
| Devanagari — **line across the top** of every word | Hindi belt, central and north |
| Devanagari **plus ळ** | **Maharashtra** (Marathi) |
| Like Hindi but **no top line** | **Gujarat** |
| Softer shapes, **broken** top bar, ਨ ਲ ਅ | **Punjab** |
| Many **left-facing triangles** | northeast (Bengali) — also Bangladesh |
| Bengali **plus ৰ ৱ** | **Assam** |
| Smooth curves, small circles, squiggly tail top right | **Karnataka** (Kannada) |
| Like Kannada **plus checkmark diacritics** on top | **Telangana, Andhra Pradesh** (Telugu) |
| Curves, straight lines, **90° angles**, dot diacritics | **Tamil Nadu** — also Sri Lanka |
| Wide semi-circles over the letters, **skull-emoji look** | **Odisha** (Oriya) |
| Curvy, many **upside-down U** shapes | **Kerala** (Malayalam) |
| Many vertical lines and right angles | **Manipur** (Meitei) |
| **Latin** script that is not English | **Mizoram** (Mizo) |
| Almost only English | **Meghalaya** |

## Poles

| See this | State |
|---|---|
| **Concrete** pole full of **holes** | **Gujarat** + Daman and Diu, Dadra and Nagar Haveli |
| **Metal** pole full of holes | **Kerala** |
| Pole split into **two sections**, Brazil-style | **Andhra Pradesh, Telangana** |
| **Mesh** metal pole | **Sikkim** |
| Thin grey metal poles, often **two close together** | northeast, Uttarakhand, Himachal Pradesh |
| Trident top, **middle insulator on the pole**, other two on a lower crossbar | **Karnataka**, sometimes Haryana |
| Trident top on an **all-metal** pole | **Manipur** |
| Trident top, middle bar **bent 90°** | **Assam** |
| Small **window-shaped** poletop | **Punjab, Haryana** |
| **Upside-down triangle** below the top | **Maharashtra, Chhattisgarh**, less often MP |
| Metal bar shaped like an **upside-down A** | **Madhya Pradesh** |
| Connector like an **upside-down trapezoid** | **Chhattisgarh**, also Meghalaya, Tripura, Maharashtra |
| Two vertical bars forming a tall narrow rectangle | **West Bengal** |
| Two crossbars joined by thin vertical supports | **West Bengal** |
| Two diagonal bars forming a **'<'** | **Meghalaya, Arunachal Pradesh**, sometimes Assam |
| Two crossbars with two insulators each | **Assam, Meghalaya, Mizoram** — more than two bars means **Meghalaya or Mizoram** |
| Short crossbar **above** a longer one | **Goa** |

**Careful — two holey poles:** concrete means **Gujarat**, metal means **Kerala**. Holey poles
beat poletop clues: when a pole has both, trust the holes. The trapezoid connector is the weakest
of these — use it only when no other pole clue is present.

**Mnemonic:** **G**ujarat = **G**ruyère, the concrete pole full of holes.

**Careful:** trident tops are the **most common pole in India overall**, so a trident says
"India", not "which state". Only the variants above narrow it down.

## Pole and tree markings

| See this | State |
|---|---|
| One black stripe between two white ones, on poles and trees | **Tamil Nadu** |
| **Five or more** thin black-and-yellow stripes | **Delhi** |
| **Exactly four** thicker black-and-yellow stripes | **Bihar** |
| Trees with four red-and-white stripes near the bottom | **Bihar**, less often Jharkhand |
| Small yellow pole markings | **Kerala** |
| Mint green electricity counters with window-like squares | **Punjab**, rarely Haryana |

## Buildings

| See this | Region |
|---|---|
| Rounded roof tiles, disorganised rows | central India |
| Bright orange flat tiles with a ridge, neatly laid | south, especially **Tamil Nadu** |
| Flat tiles with a small **diamond protrusion** in the middle | **West Bengal** and around |
| Large hip roofs of corrugated metal | **West Bengal**, adjacent Bihar and Odisha |
| Metal roofs with a small triangle near the top | northeast |
| Houses of square panels separated by thin beams | northeast |
| Thatched roofs, large hay mounds | east coast and northern plains |
| **Gurdwaras** — white domes, ornate walls, Khanda symbol | **Punjab** |

## Plants and ground

| See this | Region |
|---|---|
| **Chir pine** — smooth conical crown, very long needles | Uttarakhand, Himachal, J&K, west Arunachal |
| **Khasi pine** — jagged, disorganised crown | **Meghalaya, Manipur** |
| Cactus (Euphorbia neriifolia) used as **fencing** | Gujarat, west Maharashtra, south Rajasthan |
| **Palmyra palm** — lollipop shape | south and east, in large numbers |
| **Areca palm** — very thin trunk, small crown | southwest coast, northeast, Andamans |
| Oil palm plantations | panhandle of **Andhra Pradesh** |
| Tea plantations **on flat ground** | **Assam** or northeastern West Bengal |
| Cotton | **Gujarat, Maharashtra** |
| Canola | around **Rajasthan** |
| Distinctly **dark** soil | **Maharashtra** and around |
| **Red** soil | southern west coast, Chhattisgarh, western Odisha |
| Dry sandy desert | western **Rajasthan** |
| Extremely dry, almost no vegetation, in the mountains | **Ladakh**, northern Himachal |
