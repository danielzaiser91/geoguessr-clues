# Mexico — states

Only once you know it is Mexico.

## Signs and bollards

| See this | State |
|---|---|
| **Thick cross** on the back of a sign | **Chihuahua** |
| Bollard with a **red band** near the top | **Nayarit** — one exception, Fed 190 on the Oaxaca-Chiapas border |
| Bollard with a **crown and "Jalisco"** written on it | **Jalisco** — no other Mexican bollard carries writing |

**Mnemonic:** **C**hihuahua = **c**ross on the back.

## Poles

| See this | State |
|---|---|
| **Acorn-shaped** white insulators | coastal — mostly **Michoacán, Colima, Veracruz** |
| **Asymmetric** crossbar, double-stacked insulators | **CDMX, Edomex, Hidalgo, Morelos** |
| Wooden pole, **lowered** crossbar | **Sinaloa, Sonora** |
| **Concrete** pole, insulators **hanging below** the crossbar | **Yucatán peninsula** |
| **Wooden** version of that hanging pole | **Baja California peninsula** |
| Lowered crossbar **plus one support beam** to the pole | **Durango** |
| **Mesh** pole body | **San Luis Potosí, Guanajuato, Querétaro** |

## Numbers

- **Area code**, first digit = region.
- **Postal code** at the bottom of street signs — numbered **alphabetically by state name**, so
  a low number means a state early in the alphabet.

Both maps are on [plonkit.net/mexico](https://www.plonkit.net/mexico).

## Road surface

| See this | State |
|---|---|
| **White** middle road line | **Tabasco** |
| **Black tar** on both sides of the yellow centre line | **Sinaloa, Durango, Guerrero** |
| Grainy pavement, blue-grey tinge | **Tamaulipas, Nuevo León** — dashed outer lines on big TAM roads |
| Irregular cobblestone | **Nayarit, Jalisco, Colima, Querétaro** |
| **Hexagonal** tiles | **Puebla, Tlaxcala** |
| Three lines of cobblestone patterning | **Oaxaca** |
| Taxi: white bottom, **pink** top | around **Mexico City** |

## Plants

| See this | State |
|---|---|
| **Cardón** cactus — huge sprawling arms, ribbed | **Baja California peninsula** |
| **Saguaro** — short curving arms | western **Sonora** |
| **Organ pipe** — thin stems from ground level | **Sonora**, sometimes **BCS** |
| **Blue myrtle** — short arms curving upward | **San Luis Potosí**, also Querétaro, Hidalgo |
| **Prickly pear** — flat oval pads | central; rare in the south and on coasts |
| **Blue agave** fields | **Jalisco, Nayarit** |
| **Pulque agave** — wide curling leaves, crown-like | central valley, around San Luis Potosí |
| **Tree yucca** | **San Luis Potosí, Zacatecas** |
| **Boojum** tree — alien tentacles | southern **Baja California** |
| **Brittlebush** — silver-grey shrub | **Sonora**, especially Hermosillo |
| **Sabal palm** — lollipop crown | east coast, **Yucatán**, Nayarit |
| **Attalea rostrata** — umbrella palm | **Veracruz, Tabasco** |
| Oil palm plantations | **Chiapas** |
| Sugar cane | everywhere, by far most in **Veracruz** |
| Thin **white-barked** trees | **Quintana Roo** |
| Gold grass tufts lining the road | **Coahuila** |
| Teardrop-shaped grass clumps | around **Tlaxcala** |
| Fences made of **red-barked** trees | **Veracruz** — other coastal states too, so combine |
