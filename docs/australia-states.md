# Australia — states

Only once you know it is Australia.

| See this | State |
|---|---|
| White property marker on a black post at the roadside | **SA** |
| **Stobie pole** — two rails with a slab between them ("sandwich pole") | **SA** |
| Metal pole full of holes | **NT** |
| **Yellow** licence plate | **NSW** |
| **Yellow** sign post | **WA** |
| **White** direction sign | **TAS** |

**Careful:** yellow alone decides nothing — plate and post point to different states.

**Mnemonic:** yellow **plate** = east (NSW), yellow **pole** = west (WA).

Marker clue: [plonkit.net/australia](https://www.plonkit.net/australia).
